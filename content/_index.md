## How I work

- **Reproducible by default.** Outputs are committed next to the code that made them, with pinned references and checksums. If a number is in a report, a script regenerates it.
- **Decisions get a document.** Scoping notes, decision memos and published reports, so the reasoning outlives the meeting and the next person can see why.
- **I use AI agents, with gates.** Every change on its own branch and pull request, an adversarial review from a second model, and a human merge. Agent-written code meets the same bar as mine.
- **Results that don't hold up get corrected, not polished.** When a cross-validation score turned out to be leakage, we published the corrected number and the reason.
- **Field ecologist first.** I came to data through watershed campaigns in New Mexico and a wildlife observatory in coastal Alaska. I still ask what a measurement can and can't support before I model it.
